# GDS Stellar

Космический 3D-сайт кальянного табака GDS «Джедес» (линейка Stellar / Discover Star). Контент — из «Презентация GDS (4).pdf».

Стек: Vite, three.js (сцена, шейдеры, постобработка), GSAP, Lenis. Серверной части нет.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5180
npm run build    # статическая сборка в dist/ (пути относительные: работает и в корне домена, и в подпапке)
```

Отладочные параметры адреса: `?q=0|1|2` — зафиксировать качество графики (2 — с bloom и пост-проходом),
`?reduced` — режим без анимаций, `?low` — упрощённая сцена, `?dtmax=1` — не ограничивать шаг времени (для медленных машин).

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка всех разделов, иконки (SVG-спрайт), мета-теги |
| `src/main.js` | заставка, возрастной экран, прокрутка → состояние сцены, главный цикл |
| `src/scene.js` | рендерер, студийный свет, туманность, звёзды, луна, банка, орбита вкусов, качество |
| `src/cosmos.js` | шейдеры космоса: туманность, звёзды, боке-пыль, луна с кратерами, звезда-солнце |
| `src/jar.js`, `src/skins.js` | 3D-банка; этикетки и крышки рисуются на canvas (фольга — через карту металличности) |
| `src/fx.js` | финальный проход: хроматическая аберрация, «варп» при быстром скролле, вспышка |
| `src/data.js` | вкусы, цвета, описания, астрономические справки |
| `src/ui.js`, `src/typo.js` | курсор, магнитные кнопки, наклон карточек, появление блоков, форма; русская типографика |

Название и цвет вкуса меняются в `src/data.js` — банка, фон и звезда перекрасятся сами.

## Публикация

Сайт на этапе согласования закрыт от индексации (`noindex` в `index.html` и `Disallow` в `public/robots.txt`).
Перед открытием: убрать оба, подставить абсолютный адрес в `og:image`, проверить юридические тексты.

```bash
npm run deploy              # GitHub Pages: force-push dist в ветку gh-pages (нужен remote origin)
npm run deploy:statichost   # statichost.eu: нужны STATICHOST_SITE и STATICHOST_APIKEY в окружении
```
