# GDS Stellar

3D-сайт кальянного табака GDS «Джедес» (линейка Stellar, Discover Star). Контент взят из «Презентация GDS (4).pdf».

Стек: Vite и three.js. Библиотек анимации и плавного скролла нет: прокрутка браузерная, переходы на CSS и коротком собственном твине.
Серверной части нет.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5180
npm run build    # статическая сборка в dist/ (пути относительные: работает и в корне домена, и в подпапке)
```

Параметры адреса для отладки: `?q=2` полная сцена без автоподбора, `?q=0` упрощённая сцена, `?reduced` режим без анимаций,
`?low` облегчённая сцена как на телефоне, `?dtmax=1` не ограничивать шаг времени (для медленных машин и скриншотов),
`?hires` на телефоне и планшете вернуть полные картинки.

## Мобильная версия

- Раскладка сцены зависит от формы окна, а не только от ширины: «узкое» окно (ширина / высота меньше 0,95: телефон и планшет в портрете) ставит банку по центру,
  а текст внизу под затемнением; «низкое» окно (высота до 560 px, шире, чем выше: телефон в альбомной ориентации) уводит банку вправо и делает меньше, текст в левой половине.
  Условия в `src/main.js` (`targets()`: `narrow`, `land`) и в конце `src/style.css` должны совпадать.
- Телефонные размеры шрифтов и отступы включаются по ширине до 760 px; на низких окнах меняются только вертикальные промежутки.
- Телефон и планшет (`pointer: coarse`) получают облегчённые картинки: планеты `src/assets/planets-lo` (800 px вместо 1100), луна `moon-lo.jpg`, логотип банки `logo-md.png` (1400 px).
  В видеопамяти держатся планета упаковки, текущий вкус и по две соседних планеты с каждой стороны, остальные освобождаются (`keepPlanets` в `main.js`, `trim` в `cosmos.js`).
  Пропорции облегчённых планет те же (scene.js берёт `1100 / 1387`); при замене картинок оба комплекта обновлять вместе.
- Если WebGL недоступен, в первом экране показывается снимок банки `src/assets/poster-jar.jpg` (стили `html.no-webgl .hero::before`).
- Возрастной экран прокручивается, если не помещается в окно; шапка ниже сцены получает сплошной фон (`.nav.on-solid`, только телефон и планшет).

## Устройство

| Файл | Что внутри |
| --- | --- |
| `index.html` | разметка всех разделов и мета-теги |
| `src/style.css` | дизайн-система: один шрифт, один акцент (золото), один радиус (2px), без теней, градиентов и размытия |
| `src/main.js` | заставка, возрастной экран, прокрутка и состояние сцены, главный цикл, замер производительности |
| `src/scene.js` | рендерер (родное разрешение и MSAA, без постобработки), студийный свет, банка, орбита вкусов, режимы упрощения |
| `src/cosmos.js` | шейдеры: туманность (считается в маленький буфер), звёзды, луна с кратерами, звезда-солнце |
| `src/jar.js`, `src/skins.js` | 3D-банка; этикетки и крышки рисуются на canvas (фольга через карту металличности) |
| `src/ui.js`, `src/typo.js` | появление блоков, форма, иконки Phosphor; русская типографика |
| `src/data.js` | вкусы, цвета, описания, астрономические справки |
| `src/catalog.js`, `src/config.js` | чтение каталога из Supabase (только публичным ключом) и подстановка описаний вкусов |

Шрифт: Roboto Flex с осью ширины. Заголовки в расширенном тяжёлом начертании (повторяет пропорции логотипа), текст в обычном.

### Токены дизайна (`:root` в `src/style.css`)

Значения берутся только из токенов, новые числа в правилах не вводятся.

- Цвета: `--bg`, `--ink`, `--ink-2`, `--muted`, `--gold`, `--gold-hi`, `--err`, `--on-gold` (текст на золотом), `--surface` (карточка возрастного экрана), `--scrollbar`, `--bg-rgb` (для затемнений: `rgb(var(--bg-rgb) / 0.9)`); готовое затемнение снизу: `--scrim-up`.
- Шрифты: подписи `--fs-cap` (14 px), метки и согласия `--fs-label` (15 px), текст `--fs-body` (16 px), описание вкуса и ввод `--fs-body-lg`; заголовки считаются формулами `clamp` в `.display`, `.h2`, `.h3`, `.lead`, `.f-name`.
- Отступы: `--s-1…--s-9` (0,25 / 0,5 / 0,75 / 1 / 1,5 / 2 / 3 / 4,5 / 6 rem).
- Движение: `--dur-fast` 0,15 с, `--dur-base` 0,25 с, `--dur-slow` 0,5 с, `--dur-reveal` 0,9 с; кривая `--ease`.
- Служебные страницы (`public/404.html`, `public/privacy.html`) берут те же значения из `public/base.css` (шрифт и логотип лежат рядом без хэша); палитру при смене менять в обоих местах.
- Пара «подпись и значение» везде в порядке: подпись сверху, значение снизу. Линия поля с ошибкой и обводка флажка в `--err`.
Название и цвет вкуса меняются в `src/data.js`: банка, фон и звезда перекрасятся сами.

## Данные из Supabase

При загрузке сайт читает таблицу `products` (запрос идёт под заставкой, ждёт не дольше 2 секунд) и подставляет **описания вкусов** по совпадению `slug` с `id` в `src/data.js`. Названия, цвета, подписи банки и астрономия остаются в `data.js`: в базе их нет. Если база недоступна или ответ неверный, показываются тексты из `data.js`.
Адрес проекта и публичный ключ лежат в `src/config.js`. Они не секретные (права ограничены политиками в `supabase/migrations`); секретные ключи и пароль базы сюда нельзя.

Пока **не** поддерживается: скрытие вкуса через `is_active = false` (сайт покажет вкус из `data.js`: у каждого вкуса своя планета по номеру), вкусы, которых нет в `data.js`, названия и контакты из базы. Десятый вкус в базе называется `isida`, на сайте `auris`: он не сопоставляется, пока владелец не решит, как его называть.
Проверка модуля: `node scripts/test-catalog.mjs`; вместе с живой проверкой базы (только чтение): `LIVE=1 node scripts/test-catalog.mjs`.

## Защитные заголовки

`public/_headers` (хостинг statichost.eu применяет его при публикации) задаёт Content-Security-Policy и другие заголовки: скрипты, шрифты и картинки только со своего адреса, запросы только к себе и к проекту Supabase, нет встраивания в чужие страницы, нет `eval`, нет передачи адреса страницы, хэшированные файлы `assets/*` кэшируются на год. Если сайт начнёт обращаться к другому адресу (например, показывать картинки из хранилища Supabase), его надо добавить в `connect-src` или `img-src`, иначе браузер заблокирует запрос.
Проверено в настоящем Chrome с программным WebGL: нарушений политики нет, сцена и запрос в базу работают; чужой адрес, `eval` и вставленный скрипт блокируются. После публикации проверить: `curl -sI https://gds.statichost.page/ | grep -i content-security-policy`.

## Партнёрские заявки на почту

Форма в разделе «Контакты» отправляет заявку в программу Google Apps Script (`apps-script/lead-mailer.gs`), которая присылает письмо владельцу аккаунта Google, под которым она развёрнута. Как развернуть и проверить: `apps-script/README.md`. Адрес развёрнутой программы вписывается в `src/config.js` (`LEAD_ENDPOINT`), пока он пуст, форма открывает почтовую программу посетителя, как раньше. Если прямая отправка не удалась, форма тоже открывает почтовую программу, чтобы заявка не потерялась.
В форме два отдельных флажка (согласие на обработку данных со ссылкой на `public/privacy.html` и подтверждение возраста и вида деятельности) и скрытое поле-ловушка для ботов. Проверка без Google: `node --test scripts/test-lead.mjs`.
Пока политика не готова, `public/privacy.html` это заглушка («Документ готовится»), а черновик с пометками лежит только у владельца (`docs/privacy-draft.html`, в репозиторий не добавляется). Перед публикацией настоящей политики: `node scripts/check-privacy.mjs` (для заглушки и для черновика с пометками он завершается с ошибкой; проверить черновик: `node scripts/check-privacy.mjs docs/privacy-draft.html`).
Форма без JavaScript скрыта (вместо неё телефон и почта), у полей есть ограничения длины, ловушка для ботов называется `hp`.

## Почему нет «чёрных вспышек»

Холст очищается при любом изменении размера. Поэтому размер не меняется во время прокрутки, а единственное упрощение сцены
выполняется под заставкой или в начале кадра, непосредственно перед отрисовкой. Ниже сцены лежат сплошные блоки, и там 3D не рисуется.

## Публикация

Сайт закрыт от индексации (`noindex` в `index.html` и `Disallow` в `public/robots.txt`), пока тексты согласуются.
Перед открытием: убрать оба, подставить абсолютный адрес в `og:image`, проверить юридические тексты.

```bash
npm run deploy              # GitHub Pages: force-push dist в ветку gh-pages (нужен remote origin)
npm run deploy:statichost   # statichost.eu: нужны STATICHOST_SITE и STATICHOST_APIKEY в окружении
```
