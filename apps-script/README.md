# Приём партнёрских заявок на почту (Google Apps Script)

Форма на сайте отправляет заявку в небольшую программу Google, а та присылает письмо на почту **владельца аккаунта Google, под которым её запустили**. Ни таблицы, ни базы для заявок нет: письмо в почтовом ящике единственная копия. Адрес почты в коде не записан.

Пока адрес программы не указан в `src/config.js`, форма работает по-старому: открывает почтовую программу посетителя.

## Как запустить (один раз, около 10 минут)

Нужен аккаунт Google, на почту которого должны приходить заявки (`maksim344551@gmail.com`).

1. Откройте https://script.google.com/ и войдите этим аккаунтом. Нажмите **New project** («Новый проект»).
2. Назовите проект `GDS leads` (вверху, вместо «Untitled project»).
3. Откройте файл [lead-mailer.gs](lead-mailer.gs), нажмите Ctrl+A, Ctrl+C. В редакторе Apps Script выделите весь код в файле `Code.gs`, вставьте скопированное поверх (Ctrl+V). Нажмите **Save** (значок дискеты, Ctrl+S).
4. Вверху справа нажмите **Deploy → New deployment**. Нажмите на шестерёнку рядом с «Select type» и выберите **Web app**.
5. Заполните:
   - Description: `v1`
   - **Execute as: Me** (от вашего имени)
   - **Who has access: Anyone** (любой посетитель сайта; без этого форма не сработает)
6. Нажмите **Deploy**. Google попросит разрешения: **Authorize access**, выберите свой аккаунт. Появится предупреждение «Google hasn't verified this app»: нажмите **Advanced → Go to GDS leads (unsafe) → Allow**. Это нормально: вы разрешаете собственной программе отправлять письма от вашего имени. Других прав она не просит.
7. Скопируйте **Web app URL**. Он выглядит так: `https://script.google.com/macros/s/AKfy.../exec`. Пришлите мне этот адрес: он не секретный, а как и любой адрес сайта виден в коде страницы.
8. Я впишу его в `src/config.js`, соберу сайт и отправлю одну пробную заявку, чтобы вы убедились, что письмо пришло.

## Как проверить, что всё работает

После публикации сайта отправьте заявку через форму на сайте. Письмо придёт с темой «Заявка с сайта GDS: Имя (Компания)». Если письма нет через минуту, посмотрите папку «Спам»: откройте письмо и нажмите «Не спам». Чтобы такие письма не попадали в спам, создайте фильтр: в Gmail откройте письмо → три точки → **Filter messages like this** → **Never send it to Spam**.

## Если нужно изменить программу

Исправьте код в редакторе Apps Script, затем **Deploy → Manage deployments → значок карандаша → Version: New version → Deploy**. Адрес остаётся прежним. Если создать **New deployment**, адрес изменится, и его придётся заново вписать в `src/config.js`.

## Что программа делает и чего не делает

- Проверяет заявку: обязательны имя, телефон или e-mail, оба согласия; длины ограничены; невидимые знаки вырезаются; перевод строки в имени не может подменить заголовки письма.
- Защита от спама: скрытое поле для ботов; слишком быстрые отправки отклоняются; не больше 3 заявок в час с одного контакта и 10 в час всего; когда в дневной почтовой квоте остаётся меньше 30 писем, заявки временно не принимаются (сайт откроет почтовую программу посетителя), а вам приходит одно предупреждение.
- Пишет письмо только вам: адрес получателя берётся из аккаунта, под которым запущена программа, и поменять его извне нельзя.
- Лимит Google: на обычном аккаунте Gmail не больше 100 писем в сутки через Apps Script. Для заявок этого достаточно.
- Если заявка не прошла (нет связи, сбой), сайт сам открывает почтовую программу посетителя с готовым письмом, чтобы заявка не потерялась.
- Срок хранения: письма лежат в вашем почтовом ящике. По политике конфиденциальности заявки хранятся не дольше 6 месяцев, поэтому раз в несколько месяцев удаляйте старые: в Gmail поиск `subject:"Заявка с сайта GDS" older_than:6m`, выделить все, удалить.

Проверка кода без Google: `node --test scripts/test-lead.mjs`.
